## Projects

### TripBook

> Full-stack app for managing trip bookings — passengers, destinations and the trips that connect them.

[![Repo](https://img.shields.io/badge/GitHub-tripbook--api-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/JustAnyoone/tripbook-api)
[![Live Demo](https://img.shields.io/badge/Live%20Demo-online-brightgreen?style=flat-square&logo=render&logoColor=white)](https://tripbook-api-9dv5.onrender.com)
[![CI](https://github.com/JustAnyoone/tripbook-api/actions/workflows/ci.yml/badge.svg?branch=portfolio)](https://github.com/JustAnyoone/tripbook-api/actions/workflows/ci.yml)

A project that started as a university assignment (OOP, UniCEUB) and evolved into a full portfolio application:

- REST API built with **Spring Boot 4** and **MySQL**, secured with **JWT authentication**
- React + TypeScript front-end where every trip is displayed as a **boarding pass**
- **Dashboard** with trips per status, revenue per currency and upcoming departures
- Searchable country picker with flags, custom calendar date picker, light/dark theme
- **English and Brazilian Portuguese** with automatic browser language detection
- CSV export, loading skeletons, paginated and filterable lists
- **92 automated tests** (unit, integration, component and API client)
- Deployed on **Render** (Docker) with **Aiven MySQL** and uptime monitoring
